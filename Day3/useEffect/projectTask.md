* Project 1:  Dynamic Random Quote Generator


       API fetching aur state synchronization ki practice ke liye.
       
       Seekhne ko milega: Initial load par data lana, button click par wahi function re-trigger karna, aur loading/error state maintain karna.
       
       Requirements:
       
       Component load hote hi ek random quote aur uska author screen par dikhe.
       
       Ek "New Quote" button ho — uspe click karte hi naya quote fetch ho.
       
       Jab tak fetch ho raha ho, button disabled rahe aur screen par "Fetching new thought..." dikhe.
       
       API Endpoint (Free & Stable):
       
       [https://dummyjson.com/quotes/random]
